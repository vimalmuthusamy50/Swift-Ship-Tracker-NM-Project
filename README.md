# Swift Ship Tracker 🚚

## Project Overview

Swift Ship Tracker is a **Salesforce-based parcel management and tracking system** designed to simplify parcel booking, shipment tracking, delivery updates, and customer communication.

## Key Features

* 📦 Parcel booking and management
* 📍 Shipment status and location tracking
* 🚚 Delivery status updates
* 🔔 Automated customer notifications
* 🤖 AgentForce AI-powered parcel tracking
* ⚡ Salesforce Flow automation
* 📊 Reports and dashboards
* 🔐 Role-based security and access control
* 🌐 Experience Cloud customer access

## Technologies Used

* Salesforce Developer Edition
* Salesforce Lightning
* Custom Objects
* Salesforce Flow
* Apex & Batch Apex
* AgentForce AI
* Prompt Builder
* Experience Cloud
* Reports & Dashboards

## Main Objects

* Parcel
* Delivery
* Sender
* Receiver
